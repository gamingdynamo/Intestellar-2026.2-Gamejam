Quest 7 - COVID evolved

Type: Text message + interact.
Sanity: Hallucination
Trigger: Beginning of a Day 3 / Wednesday
Quest giver: Text message.

Summary: Players receives text message warning about COVID outbreak, suggesting to cover windows, because COVID spreads through light.
Purpose: Mess up with player.

Completion: Insanity +10. If player choose option 2 in the text message response additional +5.
Failure / Ignored: No effect.

Insanity progression: If insanity >= 25 there is a different version of the initial message.

Steps:
1. Player receives text message (resource 1). If sanity >=25 he receives different message (resource 2) instead. 
1. Player can ignore the quest or go to each window and interact. It would be great if that makes lighting a little bit more dim.
